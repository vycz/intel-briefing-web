### 1. [WikiSkill: Compiling Agent Experience into Persistent Knowledge for Skill Evolution](https://arxiv.org/abs/2608.27454v1)
> ⚡ WikiSkill 提出了一种让 AI agent 的技能与持久化知识库（wiki）协同进化的框架，把原始执行经验、累积知识和可执行技能分层梳理，并持续将经验沉淀进 wiki 供后续技能更新复用。在多个 benchmark 和模型上，它稳定超过现有 skill-evolution 方法，还发现技能进化与模型规模互补——小模型配上进化技能甚至能打赢更大的无技能模型，且技能可跨模型迁移，这为高效复用 agent 经验提供了很实用的新思路。
👤 Liyan Tang, Cyrus Rashtchian | 📅 2026-08-27

**详情:** 智能体技能包将专业知识和流程封装为可复用的资源，从而扩展AI智能体的能力。近期工作通过智能体经验自动发现此类技能，使智能体能够通过交互逐步适应。然而，指导技能开发的洞见通常散落在优化历史中，限制了其在迭代中的系统性复用。我们提出了WikiSkill，一个将智能体技能与持久化知识库（wiki）共同演化的框架。在高层面上，WikiSkill将原始执行经验、积累的知识与可执行技能相分离，同时持续将经验整合进wiki，供后续技能更新在此基础上构建。在多种基准和模型上，WikiSkill持续优于最先进的技能演化方法，并在大多数模型-基准组合中优于无技能基线。我们发现技能演化与模型扩展互补：更大的模型通常从演化技能中获益更多，而具备技能的小型模型可以超越不具备技能的显著更大的模型。我们还发现演化技能在模型间及模型家族间有效迁移，且由其他模型演化的技能可能优于自我演化的技能。最后，我们的消融研究证实，wiki中的持久化知识积累对于有效的技能演化至关重要。这些结果证明了系统性地积累和提炼智能体经验对于开发可复用、可迁移技能的价值。

### 2. [SWE-Prime: Fewer Trajectories, Better Performance](https://arxiv.org/abs/2608.27449v1)
> ⚡ SWE-Prime提出了一种多粒度、两阶段的SFT数据筛选方法，分别从轨迹和片段层面逐步过滤低质量监督信号，只选择高质量且具代表性的子集参与训练。实验证明，用该方法筛出的10%轨迹训练，在SWE-Bench Pro和Verified上分别比全量数据提升12.2%和24.2%，说明“成功轨迹”并不等于“优质轨迹”，更少但更干净的数据反而更有效。
👤 Dewu Zheng, Ruizhe Ye | 📅 2026-08-27

**详情:** 为了提升大型语言模型解决真实世界软件问题的能力，已有工作主要集中于构建大规模智能体轨迹数据集，并对成功轨迹进行监督微调（SFT）。然而，任务成功并不保证监督信号具有高质量：成功轨迹中仍可能包含无效、冗余或存在风险的步骤。直接使用此类轨迹进行SFT会引入噪声监督，并可能促使模型模仿不良的问题解决行为。为此，我们提出SWE-Prime，一种多粒度、两阶段的SFT数据选择方法，从轨迹和片段两个层面逐步筛选训练数据。具体而言，第一阶段基于过程质量、结果质量和数据代表性进行轨迹级筛选，从成功轨迹中选出一个高质量且具有代表性的子集。第二阶段进行片段级选择，将连续步骤分组为语义片段，并根据每个片段对最终解决方案的贡献、可学习性及潜在风险进行评测。在SFT过程中，所有片段均保留在序列中以维持上下文，而仅选中的片段参与损失计算。在SWE-Bench Pro和SWE-Bench Verified上的实验表明，使用SWE-Prime选出的10%轨迹子集进行训练，其效果优于在完整已解决数据集上训练，相对性能提升分别高达12.2%和24.2%。

### 3. [From Static to Dynamic: Benchmarking Real-World Code Review with MCR-Bench](https://arxiv.org/abs/2608.27442v1)
👤 Dewu Zheng, Yanlin Wang | 📅 2026-08-27

**详情:** 在现实世界的软件开发中，代码审查通常涉及开发者与审查者之间的迭代交互以提升软件质量，这使得该过程成本高昂且耗时。尽管近期研究尝试利用大语言模型（LLMs）实现自动化代码审查，但大多数方法将代码审查过度简化为单轮、静态的决策任务，未能捕捉真实审查场景中固有的多轮交互特性以及复杂的问题解决过程。为弥补这一不足，我们提出了MCR-Bench，这是首个面向真实多轮代码审查的缺陷状态感知基准。MCR-Bench涵盖五种常用编程语言，包含2,269个真实世界的多轮代码审查任务，每个任务均标注了细粒度的缺陷信息及跨轮次状态标签。MCR-Bench中的每个任务都配备了细粒度的缺陷元数据（如描述、类型、严重程度）以及动态状态注释，完整记录了缺陷在多轮审查过程中的演化轨迹。通过在MCR-Bench上对主流大语言模型进行广泛实验，我们获得了若干发现：（1）整体能力有限：实验表明，主流大语言模型在缺陷检测和缺陷生命周期状态跟踪方面的整体性能有限，且随着交互轮次增加，性能显著下降；（2）缺陷敏感性差异：大语言模型的性能在不同缺陷类型和严重程度之间差异显著，语义复杂或低显著性的缺陷被遗漏的可能性明显更高；（3）潜在失败机制：我们深入的错误分析剖析了误报和漏报的不同成因，揭示了跨轮次时间错位和长程记忆不足等关键弱点。

### 4. [RedEvoAgent: Automatic Red-Teaming Agent with Experience-Driven Skill Evolution](https://arxiv.org/abs/2608.27439v1)
> ⚡ RedEvoAgent 提出了一种黑盒 red-teaming agent，能把跨案例的攻击轨迹提炼成简洁可读的攻击技能，并通过工具效能剖析和 Deciding-Tool Attribution 自适应进化。它显著优于固定攻击和 agentic 基线，还提升了工具效率，能跨攻击模型和 execution harness 迁移，给 LLM agent 安全测试提供了更实用的思路。
👤 Junjie Zhang, Hui Liu | 📅 2026-08-27

**详情:** 基于大语言模型的智能体越来越多地部署于产品级执行框架中，在此类框架下，越狱攻击可触发有害工具使用及持久状态更改，从而比仅产生不安全文本生成带来更大风险。现有的自动化红队测试方法往往依赖固定攻击，而近年出现的智能体攻击者能够协调多种越狱工具，并通过基于轨迹的检索展现出更强的潜力。然而，此类检索可能因检索偏差和工具贡献不明确而复用具有误导性的经验，且完整轨迹会增加上下文开销并降低可解释性。我们提出RedEvoAgent，一种黑盒红队测试智能体，其将跨案例攻击轨迹提炼为简洁、人类可读的攻击技能。该攻击技能通过工具有效性剖析和决策工具归因来实现技能更新的自适应演化，并借助验证棘轮机制仅保留能够提升验证性能的更新。在多个基准、目标模型和目标执行框架上的实验表明，RedEvoAgent优于固定基线与智能体基线，提升了工具效率，并且能够跨攻击者模型和目标执行框架进行迁移。

### 5. [Mechanistic Reaction Prediction via Discrete Flow Matching on Graph-Structured Electron Occupation](https://arxiv.org/abs/2608.27429v1)
> ⚡ MAELLE 团队提出用离散 flow matching 在电子占据向量上建模化学反应，将反应物到产物的映射视为连续时间马尔可夫链，而非传统的分子图编辑。它在 USPTO-480K 上表现不输主流模型，且在结构复杂度和反应类型等 out-of-distribution 场景下更鲁棒，还能自然还原出与已知化学一致的机理路径并预测副产物。
👤 Nguyen Xuan-Vu, Octavian Susanu | 📅 2026-08-27

**详情:** 化学反应本质上是电子空间中的变换，然而大多数机器学习方法要么通过产物分子的从头生成来建模，要么通过直接作用于分子拓扑的启发式图编辑来建模。我们提出MAELLE（**M**ech\textbf{A}nistic **E**dit f\textbf{L}ow-matching on e\textbf{L}ectron r\textbf{E}arrangements，即电子重排上的机制编辑流匹配），该方法将反应建模为电子占据向量上的离散流匹配。具体而言，我们将反应物到产物的映射表述为定义在所有成键、非键和氢位点上的图结构整数取值电子占据空间上的连续时间马尔可夫链（CTMC）。为构造中间编辑轨迹，我们利用最优传输将离散流匹配混合路径推广至离散电子重排，从而在不需基元步骤标注的情况下生成一系列机制上可解释的编辑操作。在USPTO-480K基准上，MAELLE与领先的反应预测模型相比取得了具有竞争力的性能。除分布内准确性外，我们还评估了两种分布外设置下的鲁棒性——结构复杂性和反应类型——并发现MAELLE在现有方法性能下降的情形下仍能保持强劲表现。最后，由于学习到的流作用于完整的电子再分配，MAELLE自然能够恢复与已知化学一致的机制轨迹，并能预测反应的副产物。

**详情:** ### 背景
