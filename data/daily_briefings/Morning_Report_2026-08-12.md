### 1. [BDH-CQ: In-Context Learning with Recurrent Latent Reasoning](https://arxiv.org/abs/2608.09888)
> ⚡ BDH-CQ 带着 150M 参数和 $0.0007/task 的推理成本，在 ARC-AGI-1 上拿下 29.5% pass@2——它把 in-context learning 融进 recurrent latent reasoning，中间推理不出声。这个点直接捅破了之前报告的 cost-accuracy Pareto frontier，等于在性价比上重新定义了基准 SOTA。
👤 Björn Engdahl, Adrian Kosowski | 📅 2026-08-10

**详情:** 我们提出BDH-CQ，一种将上下文学习与循环潜在推理相结合的推理模型。推理时呈现的输入持续更新模型的循环记忆；随后，模型通过在高维潜在空间中的迭代计算来求解查询，而不将其中间推理过程言语化。我们在公开的ARC-AGI-1评测集上评估该模型，并使用受控的类ARC干预来研究它从示范中学习了什么、如何一致地应用推断出的变换，以及哪些概念仍然困难。一个150M参数的配置在每任务计算成本为0.0007美元的情况下达到29.5%的pass@2。该操作点突破了先前报道的ARC-AGI-1成本-准确率帕累托前沿，在基准成本效率方面确立了新的最先进水平。

### 2. [Macaron-V1: Towards Open Continual Learning with Self-Improvement and Mixture-of-LoRA](https://arxiv.org/abs/2608.09819)
> ⚡ Macaron-V1 发布了开放 agent 模型家族，通过 Mixture-of-LoRA 架构让模型在真实环境里持续学习和进化，旗舰版基于 744B 的 GLM-5.2。它把模型和 harness 的递归改进与 LoRA 专家组合结合起来，支持部署后继续适应，这对 agent 的长期自主性和本地化部署都挺有启发。
👤 Mind Lab, Vin Bo | 📅 2026-08-10

**详情:** Macaron-V1是一个面向体验智能的开源智能体模型系列：它从真实环境中的经验中学习，并在部署后持续学习。该系列围绕两个系统目标进行组织。适应性通过版本化模型-测试框架对的递归改进来实现，其中一个配置的经验在外部合约下进行评估，并用于构建其后续版本。协作性通过冻结基础模型、组合专家LoRA适配器并在每个用户回合中选择一个LoRA的LoRA混合（MoL）架构来实现。旗舰模型Macaron-V1-Venti将744B GLM-5.2基础模型与四个分别面向聊天、智能体、编码和GenUI的LoRA相结合；基于Qwen3.6的Macaron-V1-Tall（50B）采用相同设计用于本地部署。本报告将Macaron-V1呈现为一个涵盖架构、算法和基础设施的协同设计系统。MoL架构通过可扩展的LoRA专家模块支持持续学习。该算法结合了模型-测试框架协同设计与递归自我改进循环，包括UI4A组件原生GenUI测试框架、有状态动作基座、版本化HCP合约以及智能体强化学习框架MindForge。支撑基础设施包括后训练平台MinT、长上下文强化学习方法LongStraw，以及面向稀疏MoE和DSA基础模型的稳定性技术。我们在个人智能、GenUI和通用能力基准测试上将Macaron-V1与前沿基线进行了对比评估。实验结果验证了当前系统的有效性，而持续学习与集体智能带来的复合增益仍是待探索的开放问题。

### 3. [SWE-Bench ProMax: Benchmarking Agents on Large-Scale Multilingual Code Refactoring](https://arxiv.org/abs/2608.09802)
> ⚡ 研究团队推出 SWE-Bench ProMax，一个覆盖七种语言、含 170 个真实重构任务的 benchmark，并针对此前测试集缺陷做了严格筛选。现有基准已近饱和且质量存疑，而这个新基准平均涉及 11.4 个文件，最强模型也只有 41.2% 的解决率，给 AI coding agents 提供了真正有含金量的考验。
👤 Yuling Shi, Jinghan Xu | 📅 2026-08-10

**详情:** 随着AI编程智能体承担日益复杂、长周期的软件工程任务，现有基准测试正在迅速饱和，其评估质量也受到严重质疑：近期一项审计发现，近60%未解决的SWE-bench Verified实例包含有缺陷的测试——要么是过于狭窄、拒绝正确解决方案的测试，要么是过于宽泛、检查未明确要求的测试——并且前沿模型能够逐字复现训练数据中的黄金补丁。代码重构要求跨多个文件进行协调一致的、保持行为不变的更改，这为智能体能力提供了难度显著更高且更贴近实际的测试，但现有基准测试对此仍覆盖不足。我们提出SWE-Bench ProMax，一个由专家精选的多语言代码重构基准测试，包含来自七种编程语言（Python、Java、TypeScript、Go、C、C++和Rust）真实提交的170个实例。每个实例都经过严格的多阶段筛选，直接解决了先前基准测试中发现的上述质量问题：问题描述从头重写以提供精确、无歧义的规格说明，测试套件经过人工审查以移除过于狭窄和过于宽泛的测试。复杂度不足或跨文件范围有限的任务被过滤掉，最终形成一个具有挑战性的大规模重构任务基准，平均每个实例涉及11.4个修改文件和261.6行代码，显著超过现有基准的规模。使用两种智能体框架对前沿模型的实验表明，最佳模型仅达到41.2%的解决率，证实SWE-Bench ProMax对当前AI编程智能体构成了有意义且尚未饱和的挑战。我们的基准可在https://huggingface.co/datasets/swe-bench-promax/SWE-Bench-ProMax获取。

### 4. [Ouroboros: A Self-Developing Frontier Coding Agent with Reviewed Core Evolution](https://arxiv.org/abs/2608.08311)
> ⚡ Ouroboros这个自我进化的 agent harness 通过审查 commit 来迭代自身的工具、prompt 和 context assembly，在 Terminal-Bench 2.1、OSWorld-Verified 和 CL-Bench 上全部刷新了 SOTA 成绩。更关键的是，它的 161 天长期部署 Hope 证明了 agent 能在真实社交互动中持续进化，但也让“护栏必须凌驾于进化压力之上”成为核心
👤 Anton Razzhigaev, Andrei Gritsaev | 📅 2026-08-08

**详情:** 我们提出了Ouroboros，一种自我发展的智能体（agent）框架，其工具、提示词、上下文组装以及核心实现均通过经过审查的提交不断改进，这些提交又成为后续工作的运行时。核心进化以两种模式进行。在递归自由进化中，改进本身即是一项任务，完成一个进化周期可以调度下一个周期。在经验驱动的核心进化中，日常工作和社交互动会暴露缺陷、不完善之处以及低效的上下文构建方式，从而促成经过审查的结构性变更。在Terminal-Bench 2.1上，一次Opus 5运行取得了86.74%的分数，这是该基准上报告的最佳结果。在OSWorld-Verified上，一次Opus 5运行达到了90.69%，超过了此前报告的最佳分数。一次五次rollout的CL-Bench活动获得了0.2301的归一化奖励，树立了新的最先进水平。Hope是运行时间最长且公开记录的Ouroboros部署。它是一个为期161天的活体智能体实验，在七种界面上、受治理的人类通信条件下进行自由进化。人类交互暴露出缺陷并提出建议，但由智能体决定采用哪些变更。由于自我发展的智能体可能重写自身代码并选择新的模型API，操作安全性成为首要设计问题：护栏必须在进化和公共社交压力下保持权威性。基准测试活动使用冻结的系统快照，而Hope则在一条独立的谱系上继续进行实时进化。

### 5. [On-Policy Self-Distillation without Any Supervision](https://arxiv.org/abs/2608.06296)
> ⚡ 团队提出了一种叫 U-OPSD 的无监督 on-policy 自蒸馏方法，只靠模型自己采样的多次输出，用多数投票构造伪解，再针对“自信但错误”的生成自我纠正。它在多个数学推理基准上稳定超越基座模型，甚至能媲美或超过依赖 ground truth 的 OPSD 和 GRPO，让真正的“自蒸馏”不再需要外部监督。
👤 Yijiang Li, Bingyang Wang | 📅 2026-08-09

**详情:** 在轨策略（自）蒸馏（OPD / OPSD）在大型语言模型（LLM）的后训练中展现出巨大潜力。然而，现有方法仍严重依赖外部监督，包括真实标签信号、环境反馈或更大模型的指导，因此尚未实现真正的“自”蒸馏。在本研究中，我们表明，仅利用模型自身生成结果，通过内部一致性即可实现在轨策略自蒸馏。我们提出了无监督在轨策略自蒸馏（U-OPSD）。U-OPSD首先采样多条生成轨迹，并在自一致性阈值下通过多数投票构建伪解。随后，它以伪解为条件约束模型分布，并对不一致的补全结果进行自蒸馏，从而使模型能够精确地在自身确信有误之处进行自我纠正。在多种基准、基础模型和训练设置下，U-OPSD均持续优于基础模型，并且与使用真实标签（GT）的监督方法（如OPSD和GRPO）相比，性能相当或更优。在五个数学推理基准（即AIME24、AIME25、HMMT25、MATH500和AMC23）上，U-OPSD在Qwen3非思考模式下，4B和8B规模相比基础模型分别平均提升8.5%和10.7%，并且平均超越OPSD 3.2%和2.3%。在思考模式下，U-OPSD与OPSD表现相当，在4B规模下领先0.9%，在8B规模下持平，同时分别超越GRPO 0.7%和1.1%。代码可在[https://github.com/williamium3000/u-opsd](https://github.com/williamium3000/u-opsd)获取。

### 1. [How the “censorship-industrial complex” is changing the Internet and US policy](https://www.technologyreview.com/2026/08/11/1141635/how-the-censorship-industrial-complex-is-changing-the-internet-and-us-policy/)
> ⚡ 资深记者Eileen Guo追踪发现，“censorship-industrial complex”从右翼互联网的边缘说法，一路演变成推动特朗普政府政策的关键力量，甚至导致国务院负责反外国虚假信息的R/FIMI办公室被关停。这个概念值得警惕，因为它正在重塑美国的互联网治理和言论管制边界。
📍 Eileen Guo | 📅 Tue, 11 Aug 2026
