### 1. [Detect Before You Attribute: Cascade Failure Attribution for Multi-Agent Systems](https://arxiv.org/abs/2608.29646v1)
> ⚡ DUOTRACE 提出了一种 detect-before-attribute 的即插即用检测过滤器，先用 VAE 识别异常执行，再为下游 LLM 归因提供更精准的轨迹证据。它把语义和结构信息融合成节点表示，并配合 Tree-LSTM 编码器处理层级轨迹，实验显示能让 agent 级和 step 级归因准确率分别提升 8.7% 和 7.0%，对提升 LLM agent 可靠性挺有价值。
👤 Jiayi Zhang, Zexin Wang | 📅 2026-08-30

**详情:** 基于大语言模型（LLM）的智能体已展现出通过多步推理解决复杂任务的强大潜力，但其仍易遭受执行失败的影响。因此，准确的失败归因对于提升智能体可靠性至关重要。现有的基于拓扑和基于频谱的方法利用轨迹结构，但往往忽略细粒度的语义信息，而基于LLM的归因方法虽能捕获语义线索，却因长轨迹导致的长上下文退化而受影响。为应对这些挑战，我们提出DUOTRACE，一种即插即用的检测过滤器，用于基于LLM的失败归因。DUOTRACE遵循“先检测后归因”范式：首先检测异常执行，然后向下游基于LLM的归因方法提供聚焦的轨迹证据。为在智能体轨迹上实现有效的基于VAE的异常检测，DUOTRACE融合了双视图语义-结构节点表示、基于Tree-LSTM的轨迹编码器，以及基于前缀链和LLM的数据增强，以处理异质节点、层级执行结构和有限的失败数据。基于六种LLM归因基线的实验表明，DUOTRACE在智能体级和步骤级归因准确率上分别提升了8.7%和7.0%。

### 2. [Conducting Stylistic Analysis of Paintings through an Art-History Agent](https://arxiv.org/abs/2608.29644v1)
> ⚡ 团队用视觉Transformer和稀疏字典学习训练AI，自动解析画作的风格特征，再交给LLM将视觉特征转成文字描述，实现可解释的风格分析。这填补了现有AI只能给概率、无法给出艺术史论据的空白，为数字人文和计算艺术史开辟了新路子。
👤 Marc S. Walton, Astrid Harth | 📅 2026-08-30

**详情:** 将一件艺术作品归属于某位艺术家，传统上依赖于细致的视觉观察与描述，即艺术史中所称的风格分析。相比之下，当前该领域使用的人工智能（AI）模型仅提供无法解释的概率分类。为弥合这一方法论上的差距，我们提出了一种AI框架，可自动对绘画进行风格分析，为加强证据收集、发现与验证奠定基础。通过在有元数据的大型绘画语料库上训练视觉变换器（ViT），我们的系统将这种艺术史特定数据编码为嵌入表示。这些表示通过稀疏字典学习被分解为一组在训练集中反复出现的共享特征。随后，大语言模型（LLM）通过检索相关艺术作品及其附带的策展人撰写的文本，对每个特征进行解读，并将其综合为反映其风格属性的描述。最后，一个自主协调LLM应用推理与行动（ReAct）框架，对这些特征进行加权、测试和提炼，形成对某件艺术品的连贯描述，或对不同艺术品的比较。该方法将细粒度视觉特征转化为描述性术语，解决了艺术史中的一个关键挑战。由此，它将图像作为数据的运用与人文学者的语义关切联系起来，确立了基于视觉的计算艺术史作为未来发展的领域。

### 3. [LLMODE: Aligning ODEs with LLMs via Gated Token Injection for Irregular Spatio-Temporal Forecasting](https://arxiv.org/abs/2608.29640v1)
> ⚡ LLMODE框架用图感知ODE编码器把不规则时空观测重建为连续轨迹，再用固定预算重采样器压缩成动态记忆token，并注入冻结的LLM。它在城市数据和物理基准上表现优异，尤其在稀疏采样下零样本泛化强，为不规则时空预测提供了新思路。
👤 Di Zhang, Jingyang Zhang | 📅 2026-08-30

**详情:** 大语言模型（LLMs）在时空预测领域展现出应用潜力，但现有方法通常依赖规则采样的令牌序列，由于时间异步性、表示空间错位以及有限的上下文窗口，难以处理不规则观测。我们提出LLMODE，一种面向不规则时空预测的令牌高效框架，采用冻结的大语言模型骨干。LLMODE首先使用图感知ODE编码器将不规则图观测重建为连续时间潜轨迹。随后，固定预算Perceiver重采样器将该变长轨迹压缩为固定数量的动态记忆令牌。与此同时，紧凑的统计描述符被编码并重采样为上下文记忆令牌。双源门控交叉注意力模块将两种记忆注入冻结的大语言模型，从而实现对外部时空证据的可控利用。在三个真实世界城市数据集和两个物理动力学基准上的实验表明，整体性能具有竞争力，且在稀疏或动态复杂的不规则采样场景下优势更为明显。在未见城市区域上的额外评估进一步证明了无需适配的强零样本泛化能力。

### 4. [MI-Distillation: Selecting from Model-Interpolated Instruct-Reasoning Data Spectrum for Chain-of-Thought Distillation](https://arxiv.org/abs/2608.29623v1)
> ⚡ 研究者发现直接把长链推理（Long CoT）蒸馏进小模型效果有限，甚至不如短链，并从梯度视角揭示其根源是更新方向和幅度失衡。为此他们提出MI-Distillation框架，配合可学习的SeqLSS评分来挑选既信息丰富又易学的推理路径，显著提升了小模型的CoT蒸馏效果。
👤 Yangsong Lan, Renkai Hu | 📅 2026-08-30

**详情:** 近年来，大型推理模型（LRMs）的进展展现了其通过长思维链（Long CoT）推理在复杂问题上的强大性能。然而，将这些推理轨迹蒸馏到较小的学生模型中仍具挑战性：直接使用长思维链监督通常收益有限，甚至可能不如简洁的短思维链（Short CoT）解释有效。在本工作中，我们从梯度视角研究这一现象。我们的分析表明，与短思维链相比，长思维链会引发更大的梯度幅度和更集中的更新方向，且这一效应随着学生模型能力的增强而愈发显著。这些发现表明，有效的长思维链蒸馏需要在推理轨迹的推理信息密度与其对学生模型的分布对齐之间取得平衡。受此启发，我们提出**模**型**插**值**蒸**馏（**MI-Distillation**）框架，通过模型插值构建连续的指令-推理数据谱系。为从该谱系中选取合适的轨迹，我们进一步引入**序**列**可**学习**惊**讶度**评**分（**SeqLSS**），该评分偏好对学生模型既有信息量又具可学习性的推理路径。在推理基准上的大量实验表明，MI-Distillation 在强长思维链基线上持续提升了小模型 CoT 蒸馏的性能。

### 5. [AgenticRag-R1: Agentic Reinforcement Learning with Stack Memory for Multi-Step Reasoning, Retrieval and Memorizing](https://arxiv.org/abs/2608.29622v1)
> ⚡ AgenticRag-R1 提出了一套新的 RL 训练框架，把推理、检索和记忆通过 memory stack 和细粒度动作空间深度整合，并引入分层奖励与轨迹筛选机制。它在多跳、开放域和 agentic reasoning 基准上稳定超过强基线，说明这种设计能有效缓解 long-horizon 推理中的奖励稀疏和策略退化问题，让 LLM 的检索行为更稳健、更可解释。
👤 Xinke Jiang, Yue Fang | 📅 2026-08-30

**详情:** 检索增强生成（RAG）提升了大型语言模型（LLMs）的事实性，然而现有的RAG系统在处理复杂的、需要自适应检索与中间上下文持续修订的多步推理任务时，往往力有不逮。近期的基于强化学习（RL）的智能体RAG方法虽在一定程度上缓解了该问题，但其通常依赖于粗粒度的动作空间和轨迹级奖励，导致奖励分配薄弱，并倾向于产生短视的、刻板的推理模板。为此，我们提出了AgenticRag-R1，一种强化学习框架，通过记忆栈和细粒度动作空间将推理、检索与记忆深度融合，并辅以层级化的动作感知奖励和信息感知的轨迹拒绝策略，以实现有效的长程学习。在涵盖多种骨干模型规模的多跳、开放域及智能体推理基准测试上的实验表明，AgenticRag-R1始终优于强基线方法。此外，AgenticRag-R1学习到了更鲁棒、更具可解释性且记忆感知的推理行为，彰显了细粒度动作建模与信息感知优化对长程推理的效用。我们的代码以匿名形式发布于 https://github.com/jiangxinke/Harness-RL/tree/AgenticRAG-R1-Whitebox。
