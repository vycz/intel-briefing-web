### 1. [Learning When to Trust via Selective Context Preference Optimization](https://arxiv.org/abs/2608.06377v1)
> ⚡ 研究团队提出MIST基准和SC2W指标，系统量化语言模型被误导信号带偏的现象，并推出SCOPE方法，用DPO优化匹配偏好对来削弱这种脆弱性。这项工作的关键在于把问题重新定义为选择性信任——模型既要抵抗误导，又不能无视可靠上下文，为提升LLM的鲁棒性提供了更均衡的评测与训练思路。
👤 Xian Sun, Wei Chow | 📅 2026-08-06

**详情:** 语言模型越来越依赖外部信号来给出答案，而一个具有误导性的信号就足以使原本正确的答案出错。显而易见的补救措施——训练模型抵抗此类信号——却隐藏着一种失效模式：一个忽略一切上下文的模型看似稳健，但当上下文值得信赖时却毫无用处。我们将这一问题重新定义为选择性信任，并引入MIST——一个由人工标注的基准数据集，它在四种匹配条件下呈现每个推理条目（干净、误导性、正确上下文和无关上下文），同时提出SC2W——一种配对指标，用于统计误导性信号将原本干净正确的答案翻转为错误答案的频率。在一项全面的基准研究中，我们观察到这种易感性具有普遍性。随后，我们提出了SCOPE，该方法挖掘干净正确/误导性错误这类失败样本，并在四种条件间均衡配对的偏好对上优化标准直接偏好优化（DPO）目标，而非仅针对误导性条目进行优化。我们的方法显著降低了主流开源模型上的SC2W，同时在新增上下文为干净、正确或无关时保持准确率。通过这项工作，我们主张模型的评判应基于选择性信任，而非单纯抵抗能力。

### 2. [Tracing the Heart: An Evidence-Linked Pipeline for Heart-Failure Feature Engineering](https://arxiv.org/abs/2608.06366v1)
> ⚡ nMAS 团队开发了一个基于证据和评分规则的自动化特征工程系统，专门处理心衰相关的 EHR 数据，并在 500 份模拟病历中验证了效果。它能把 AUROC 最高提升到 0.963，且全程可审计，这意味着复杂心血管数据里的特征提取终于可以脱离手工了，不过目前还只在一家机构的数据上测试过。
👤 Soorya Ram Shimgekar, Michelle Hu | 📅 2026-08-06

**详情:** 电子健康记录（EHR）特征工程是临床研究和人工智能领域的主要瓶颈，占数据科学家工作量的39-45%。这一问题在心力衰竭领域尤为突出，该疾病影响约670万美国成年人，需要将碎片化的EHR数据与基于指南的疾病特异性临床推理相整合。现有的基于规则的方法和基于大语言模型（LLM）的方法仅能提供部分自动化，且可维护性和证据可追溯性有限。我们开发了Nimblemind多智能体系统（nMAS），这是一个基于证据关联、以评分标准为基础的自动化心力衰竭特征工程流水线，并在来自九个EHR源表的500份模拟患者记录上进行了评估。nMAS生成了132个结构化特征和70个经评分标准评分的聚合特征，验证了其结构完整性、评分标准合规性和来源可追溯性，并由受限大语言模型进行了审计。添加聚合特征后，HFrEF表型分类的留出集AUROC从0.895提升至0.963，HFpEF表型分类从0.870提升至0.910；独立的基于大语言模型的评分标准评估（涵盖证据支持和方法学严谨性）给予这些特征最高分的81.5%。这些结果证明了针对复杂心血管EHR数据进行自动化、可审计特征工程的可行性，但评估仅限于单一机构队列，仍需外部验证。

### 4. [An Optimal Agnostic PAC Algorithm](https://arxiv.org/abs/2608.06363v1)
👤 Markus Engelund Mathiasen, Jian Qian | 📅 2026-08-06

**详情:** 设 \(H\subseteq\{-1,+1\}^X\) 是有限 VC 维 \(d\ge1\) 的一个类别。记 \(L\) 为二值风险，\(L^*=\min_{h\in H}L(h)\)，我们构造了一个学习器，其达到统计最优的风险界：对于来自大小为 \(n\) 的 i.i.d. 样本，对每个 \(0<\delta\le 1/2\)，以至少 \(1-\delta\) 的概率有
\[
L(\widehat h) \le L^*+ 7\cdot10^8\left( \sqrt{\frac{L^*(d+\log(1/\delta))}{n}} +\frac{d+\log(1/\delta)}{n} \right).
\]
这就在每个固定的 \(L^*\) 下确定了不可知 PAC 学习的样本复杂度（至多相差通用常数），并与 Devroye、Györfi 和 Lugosi 的著作 [A Probabilistic Theory of Pattern Recognition, Springer, 1996] 中的下界相匹配。

### 5. [AV-AIVAT: 74x Cheaper Agent Evaluation with Certified Anytime-Valid Stopping in Imperfect-Information Games](https://arxiv.org/abs/2608.06362v1)
> ⚡ AV-AIVAT 把 AIVAT 的方差缩减和 Confidence Sequences 结合，能在证据充足时立刻停止 agent 对决评估，且统计保证不失效。它让原始数据需 74 倍手数才能停的场景缩到 1.37 倍左右，既支持渐进筛选也支持精确认证，省下大量推理成本和时间。
👤 Boning Li, Yu Chen | 📅 2026-08-06

**详情:** 判定两个智能体孰强孰弱，意味着持续对局直至技巧胜过运气，而每一局都要花费金钱、模型推理或专家时间。由于所需对局数未知，固定预算的评估要么在结果已定时仍在继续付费，要么在智能体尚未能被区分之前就提前停止；而使用普通置信区间的朴素可选停止会使声称的置信水平失效。我们使此类评估在其证据足够的那一刻停止，且保证依然成立。行动知情价值评估工具（Action-Informed Value Assessment Tool，AIVAT）通过条件零均值修正降低不完美信息博弈中的方差，在覆盖71,439手配对单挑无限注德州扑克（HUNL）的15种LLM智能体配置中，中位数降低$54\times$，但它并未说明何时停止。我们将AIVAT与持续监测的置信序列（Confidence Sequences，CSs）结合，提出任意有效的AIVAT（anytime-valid AIVAT，AV-AIVAT），其在线价值模型仅从过去的对局中学习，因此没有任何对局会为自己的修正打分。在名义95%水平、目标精度为$\pm1$大盲注的条件下，原始结果在中位数上需要AIVAT修正结果$74\times$的手数才能在渐近置信序列（Asymptotic CS，AsympCS）下停止。精确的有限样本认证使用经验-伯恩斯坦置信序列（Empirical-Bernstein CS，EB-CS），它需要对修正后收益有一个独立证明的界。我们针对Leduc德州扑克在结构上建立了这样一个界，并刻画了由CS的下注上限与该界共同决定的宽度下限，该下限支配着方差收益中有多少能转化为更早的停止；描述性的HUNL EB-CS运行显示停止时间比中位数为$1.37\times$。AV-AIVAT将方差降低转化为高效、可审计的提前停止，同时将渐近筛选与精确认证分离，使评估能在证据足够的那一刻立即停止，并将该停止时刻复核结论所需的一切交给第三方。
