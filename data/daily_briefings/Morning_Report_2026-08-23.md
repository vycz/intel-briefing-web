### 1. [EnvHarness: Awakening Static Worlds for Agent Learning](https://arxiv.org/abs/2608.19880)
> ⚡ EnvHarness 团队提出了一款可编程环境层，通过即插即用组件包装静态环境，结合 EnvRigger 自动观察 agent 轨迹并生成针对性优化，无需改动底层逻辑。它让环境能随策略持续进化，在五个基准上最高提升 9.0 分，还减少了 9.8% 的执行步数，给 RL 提供了更优的优化信号。
👤 Chengsong Huang, Zifeng Wang | 📅 2026-08-20

**详情:** LLM代理通过与环境的交互进行学习，然而这些环境是手工构建且静态的：它们对代理的弱点视而不见，并且随着代理能力的提升很快就会被抛在后面。尽管最近的环境生成方法试图解决这一问题，但它们需要特定领域的流水线，依赖昂贵或不可靠的验证器，并且仍然产生静态环境。为了减轻从零开始重建环境的工程负担，我们提出了环境调控框架（EnvHarness），这是一个由即插即用组件构成的可编程层，它包裹静态环境以重塑其行为，而无需修改底层逻辑。EnvHarness通过标准接口运作，可适用于多个不同领域，同时确保每个被重塑的环境保留其原有的验证器。为自动化这一过程，我们引入了EnvRigger，它将目标策略视为黑箱，通过观察其执行轨迹来综合生成针对所诊断缺陷的EnvHarness组件，并通过全新的推演进行验证。在四个领域的五个基准测试中，EnvHarness的性能优于原始环境和特定领域的环境生成流水线，在保留测试实例上实现了最高9.0分的提升，且执行步骤减少了9.8%。此外，EnvHarness为强化学习提供了更优的优化信号，使策略及其环境能够持续、有针对性地协同进化。

### 2. [SemComp-Bench: Benchmarking Semantic Task Completion in Video Generation](https://arxiv.org/abs/2608.17426)
> ⚡ 团队提出了一种面向结果的视频生成任务 Semantic Task Completion Video Generation，并配套构建了 SemComp-Data 数据集和 SemComp-Bench 评估协议。实验显示，现有视频生成模型在达成预期结果并保持与参考图语义对齐方面仍有明显差距，这为后续研究指明了优化方向。
👤 Keyu Tu, Zhuowei Chen | 📅 2026-08-18

**详情:** 我们提出语义任务完成视频生成（Semantic Task Completion Video Generation），这是一种面向结果的视频生成任务。在该设定下，成功既要求达成预期结果，也要求具备语义基础。语义基础刻画了参考图像与生成结果之间在与任务相关的高层语义上的对应关系。评估聚焦于生成结果，既不需要呈现完整的中间任务步骤序列，也不要求与参考图像具有传统意义上的外观一致性。为支持系统性评估，我们构建了SemComp-Data，这是一个覆盖六个领域的评估数据集。每个实例包含一张参考图像、一条详细指令、一条简短指令以及一段以结果为中心的视频片段。一个可扩展的四阶段整理流程将原始视频转换为标准化的SemComp-Data实例。我们进一步提出SemComp-Bench，这是一种使用视觉语言模型（VLM）回答结构化二值问题的评估协议。SemComp-Bench分别报告用于衡量结果达成（Outcome Achievement）的OA分数和生成可靠性（Generation Reliability）的GR分数。在代表性视频生成模型上的实验表明，在保持参考图像中与任务相关的语义基础的同时实现预期结果，仍然具有挑战性。

### 3. [Zetta ζ: An Efficient Closed-Loop Embodied Harness for Self-Evolving Physical Intelligence](https://arxiv.org/abs/2608.16590)
👤 Xin Ding, Liang Mi | 📅 2026-08-17

**详情:** 具身智能体正越来越多地被用于弥合端到端策略模型所留下的差距。然而，智能体路径尚未在物理执行中实现闭环学习：现有执行框架在很大程度上仍是开环的，在 rollout 过程中遵循固定技能，并且仅在一个回合结束后进行反思。这种事后反思无法在执行展开过程中对其进行管控，因为物理交互要求决策以超过当今大型智能体模型所能达到的频率，去跟踪快速变化的机器人-环境状态。我们提出了 Zetta，一个闭环具身执行框架，它在线演化基于代码的运行时评论器与恢复技能，同时保持基础策略冻结。通过三个时间尺度分离的循环，Zetta 提供了动作频率治理、rollout 级评论器-恢复提议以及验证门控的技能更新。结合 Z-Infra（一种将智能体逻辑与异构执行资源解耦的 rollout 基础设施），Zetta 在当前 rollout 预算下于 LIBERO-Pro 和 RoboCasa 上取得了最先进的成功率，分别达到 90.8% 和 93.6%，并实现了 11.1 倍的推理加速；成功率随自探索经验持续扩展；所学技能可零样本迁移，并且出现了清晰的机器人“顿悟时刻”。这些结果表明，闭环执行框架的自我进化为可靠的物理智能开辟了一条扩展路径。

### 4. [SemaPLC: A Project-Grounded, Verification-Gated Agent Harness for PLC Code Generation](https://arxiv.org/abs/2608.18565)
> ⚡ SemaPLC 是一个由外部检查驱动的 PLC 代码生成框架，只有通过编译和实时运行验证才判定任务完成。它在七种模型上达到最高严格通过率，尤其在动态行为上大幅领先，说明执行验证比静态打分更能检验生成逻辑是否真正可用。
👤 Yanlun Tu, Huacan Wang | 📅 2026-08-19

**详情:** 可编程逻辑控制器（PLC）运行着工业工厂，而大型语言模型已能够为它们生成独立的程序组织单元（POU）。此类逻辑能否集成到现有PLC项目中并正确运行，目前仅在有限的测试中得到过验证。我们提出了SemaPLC，一个基于项目、以验证为门槛的智能体框架，由常规工具组装而成，但受严格的完成规则约束。SemaPLC并非在模型自认为输出足够时停止，而是在记录在案的外部检查确认通过后才宣布任务完成。这些检查涵盖规格说明、编译以及在实际运行时上的行为。在匹配现有基准的117个独立POU任务上，它在全部七个模型上取得了最高的严格验证通过率（平均72.6%）。在包含65个任务的项目上下文轨道中，生成的逻辑必须在真实项目内编译并运行，SemaPLC在集成编译、静态行为和动态行为方面均取得了最高平均值。在这三个层面中，动态行为最具揭示性。我们通过将生成的逻辑与参考逻辑部署到实际PLC运行时并比较它们执行的轨迹来对其进行度量。所有方法彼此间的静态得分差距在10个百分点以内，而动态得分则将它们显著区分开来：基线为22.4至31.4，而SemaPLC为52.2。总体而言，我们的验证门槛框架在每个层面都提升了平均值，并在运行时层面提升最为显著。执行，而非静态评分，才是检验生成的控制逻辑是否真正有效的可靠标准。SemaPLC已在https://github.com/midea-ai/SemaPLC 开源。

### 5. [FACET: Preserving Source Intent and Executable State in Terminal Task Synthesis](https://arxiv.org/abs/2608.18580)
> ⚡ FACET 框架将分散的 agent 技能重构为信息丰富的终端任务，并同步修复执行环境，确保 instruction、solution 与 verifier 基于同一容器状态对齐。它通过执行验证和定向修复生成带密集检查的复杂任务，微调多规模模型后稳定提升 Terminal-Bench 2.1 性能，为可扩展终端任务合成提供了环境锚定的新范式。
👤 Kou Shi, Zun Wang | 📅 2026-08-19

**详情:** 训练终端智能体需要可扩展的可执行监督，然而合成高质量的终端任务仍然具有挑战性。每个任务将指令、初始化环境、参考解决方案和可执行验证器耦合在一起；如果这些构件由不一致的假设生成，最终的任务可能无法解决或被错误评估。同时，多阶段合成可能会丢弃原始源中编码的目标、依赖关系、状态转换和程序性约束。我们提出了FACET（可执行任务的细粒度智能体构建）框架，它同时解决了信息保留和跨构件一致性问题。FACET将相关的智能体技能重建为连贯、信息丰富的场景，然后在生成最终任务构件之前实现并修复执行环境。最终的容器状态作为指令、解决方案和验证器的共享基础，而基于执行的验证和针对性修复能够纠正特定构件的失败，而无需不必要地重新生成有效组件

### 1. [The Download: threats from space mirrors and credit for AI drugs](https://www.technologyreview.com/2026/08/21/1142762/the-download-space-mirrors-threats-ai-designed-drugs-credit/)
📍 Thomas Macaulay | 📅 Fri, 21 Aug 2026

**详情:** ### 背景

本期《The Download》聚焦两项前沿科技引发的治理难题：一是私营公司计划部署太空反射镜实现按需阳光供给，二是生成式AI在药物研发中的角色对传统专利发明人制度的冲击。两者分别代表了技术能力跃升对天文观测环境和知识产权规则的挑战，反映出创新速度往往快于社会规范与法律框架的更新。

### 关键发现

Reflect Orbital公司拟于今年晚些时候发射一面18×18米的轨道试验镜，最终计划部署多达5万颗更大的卫星，将阳光定向反射至地面，用于太阳能电站补光、应急响应及军事用途。但新研究警告，此类光束亮度可能相当于1万轮满月，并在数十公里范围内产生散射，严重威胁暗夜天文观测、航空安全及野生动物习性。另一方面，Insilico Medicine在宣传其AI生成的特发性肺纤维化候选药物时声称“由生成式AI发现”，却在专利申请中将五名人类列为发明人。这一矛盾凸显现行专利法只承认自然人发明者，无论AI在发现过程中贡献多大。

### 技术细节

空间反射镜的技术原理并不复杂，难点在于大规模星座的协同控制与光束指向精度。研究表明，单面镜的光污染影响半径远超预期，需建立新的亮度评估标准与轨道占位规则。AI制药领域，Insilico的系统已能像ChatGPT生成文本一样快速生成候选分子结构，但专利审查要求“发明人”必须具备对发明构思的实质贡献。实际科研中，算法设计者、数据提供者、模型训练者与验证实验者之间的贡献边界愈发难以界定，而法律尚未提供衡量AI“智力参与”的客观标准。

### 实用价值
