### 1. [EnvHarness: Awakening Static Worlds for Agent Learning](https://arxiv.org/abs/2608.19880)
> ⚡ EnvHarness 和 EnvRigger 提出了一套可插拔的组件层，能在不修改底层逻辑的前提下重塑静态环境，自动针对 LLM agent 的弱点生成训练场景。它跨五个基准测试均优于原始环境，还让强化学习信号更精准，实现了策略与环境的持续协同进化。
👤 Chengsong Huang, Zifeng Wang | 📅 2026-08-20

**详情:** LLM智能体通过与环境的交互进行学习，然而这些环境是手工构建且静态的：它们对智能体的弱点视而不见，并且随着智能体的进步很快被抛在后面。尽管近期的一些环境生成方法试图解决这一问题，但它们依赖于特定领域的流程，需要昂贵或不可靠的验证器，并且仍然产生静态环境。为了减轻从零开始重建环境的工程负担，我们提出了环境驾驭框架（EnvHarness），这是一个由可插拔组件构成的可编程层，它包裹静态环境以重塑其行为，而无需修改底层逻辑。EnvHarness通过标准接口运行，可适用于多种不同领域，同时确保每个重塑后的环境保留其原有的验证器。为使该过程自动化，我们引入了EnvRigger，它将目标策略视为黑盒，通过观察其执行轨迹来综合生成针对已诊断缺陷的EnvHarness组件，并通过全新的轨迹展开对其进行验证。在四个领域的五个基准测试中，EnvHarness的性能优于原始环境和特定领域的环境生成流程，在保留实例上取得了高达9.0分的提升，同时执行步数减少了9.8%。此外，EnvHarness为强化学习提供了更优的优化信号，使得策略与其环境能够实现持续、有针对性的协同进化。

### 2. [FACET: Preserving Source Intent and Executable State in Terminal Task Synthesis](https://arxiv.org/abs/2608.18580)
> ⚡ FACET框架提出了一种细粒度可执行任务构建方法，通过先修复环境、再生成指令、解法和验证器，确保多阶段合成时信息不丢失且各组件一致。它生成的终端任务带密集可执行检查，其轨迹能高效微调模型，在Terminal-Bench 2.1上稳定提升性能，证明环境锚定是规模化合成的关键。
👤 Kou Shi, Zun Wang | 📅 2026-08-19

**详情:** 训练终端代理需要可扩展的可执行监督，然而合成高质量的终端任务仍具挑战性。每个任务都耦合了指令、初始化环境、参考解决方案和可执行验证器；如果这些工件是在不一致的假设下生成的，所得到的任务可能无法求解或被错误评估。与此同时，多阶段合成可能会丢弃原始来源中编码的目标、依赖关系、状态转换和过程约束。我们提出了FACET（可执行任务的细粒度智能体构建），这是一个同时解决信息保持和跨工件一致性的框架。FACET将相关的代理技能重构为连贯的、信息丰富的场景，然后在生成最终任务工件之前实现并修复执行环境。所得出的容器状态为指令、解决方案和验证器提供了共享基础，而基于执行的验证和针对性修复则纠正特定于工件的故障，无需不必要地重新生成有效组件。FACET生成了具有密集可执行检查的复杂终端任务，从这些任务中收集的成功轨迹提供了有效且数据高效的监督。跨多种规模微调模型持续提升了Terminal-Bench 2.1上的性能，而对替代生成方案的分析则支持了以环境为基础的构建对任务有效性和解决方案-验证器一致性的重要性。这些结果确立了源意图保持和共享可执行状态基础作为可扩展终端任务合成的关键原则。

### 3. [4DAnyone: Create Anyone in 4D from a Casual Monocular Video](https://arxiv.org/abs/2608.20335)
👤 Yudong Jin, Tao Xie | 📅 2026-08-20

**详情:** 我们提出了4DAnyone，这是一个从未标定的单目视频中重建4D人体的框架，其方法是通过生成重建级的多视角一致性视频并将其提升为4D高斯溅射（4DGS）。现有的基于相机控制的视频扩散模型能够生成看似合理的新视角视频，但当视角数量扩展到4DGS重建所需的数十个目标视角时，这些模型无法保持一致性。我们将这一失败归因于有界注意力上下文问题：当目标视角超过单个DiT前向传播的容量时，必须将其分组处理，从而暴露出两个相互耦合的瓶颈。在参考上下文方面，对所有先前生成视角的条件依赖以O(N)的速度增长，削弱了跨视角的外观引导。在目标上下文方面，不相交的组无法直接交换信息，导致全局结构漂移。4DAnyone通过两种互补设计来解决这两个瓶颈：参考上下文打包（RCP）将不断增长的参考视角压缩为固定长度的混合分辨率上下文，实现O(1)的参考上下文复杂度；目标上下文路由（TCR）在去噪过程中轮换目标视角的分组方式，在高噪声步骤中跨组共享上下文，在低噪声步骤中稳定细节。我们进一步利用自研游戏引擎构建了MVGameHuman数据集，并将其与光stage和野外视频数据集结合用于训练。在DNA-Rendering和DyMVHumans上的实验表明，4DAnyone在新视角视频质量和下游4DGS重建方面均优于现有方法，并具有稳健的野外泛化能力。视频结果和源代码见我们的项目页面：https://4danyone.github.io。

### 4. [SWE-bench Science: Can Coding Agents Resolve Engineering Tasks in Science?](https://arxiv.org/abs/2608.19799)
> ⚡ 我们推出了SWE-bench Science，一个覆盖20个科学领域、含119个仓库级任务的基准，用于评估编程智能体修复科学软件的能力。结果显示最强模型Claude Code的pass@1也不足50%，并暴露出科学知识缺失、表面修复等四类失败机制；进一步实验还发现科学指导并非总有益，错误信息反而会拖累修复效率。
👤 Zhipeng Xu, Jiahao Lu | 📅 2026-08-20

**详情:** 软件日益成为科学仪器本身的一部分，这使得科学代码中的故障不仅可能损害程序行为，还可能损害支撑科学结论的证据。然而，现有对编码代理的评估大多侧重于总体任务成功率，对代理在修复科学软件时为何失败所提供的洞察十分有限。我们推出了SWE-bench Science，一个面向科学软件工程的仓库级基准测试，包含来自20个科学领域、98个GitHub仓库的119个任务。每个任务归属于三种范式之一：问题驱动型（Issue-driven）、专家探索型（Expert-exploratory）和工程集成型（Engineering-integration）。即使性能最佳的代理Claude Code with Opus-5（max），其pass@1也低于50%，凸显了科学软件工程所带来的巨大挑战。我们识别出四种反复出现的失败机制：科学知识或抽象能力不足、探索方向误导或仅停留在表层修复、修复覆盖不完整或系统集成缺失，以及在我们的分析中未能将科学知识泛化到所观察案例之外。我们进一步进行了配对消融实验，在保留仓库和可执行的工程上下文的同时，移除显式的科学指导。结果表明，科学知识并非一律有益：有充分依据的信息可以约束修复过程，提升平均性能和令牌效率；而匹配不当的指导则可能引发锚定效应，且不一定会提升精确修复成功率。综上，SWE-bench Science为研究编码代理在科学软件工程中的能力与失败机制提供了一个广泛的测试平台。

### 5. [WithEveryone: Unified Planning and Identity Grounding for Group Image Generation](https://arxiv.org/abs/2608.20336)
> ⚡ WithEveryone 框架提出了一种统一方案，可生成包含多达十位指定身份的群像，通过注入寻址 token 和布局计划实现身份与位置的精确绑定。它用 Layout-Grounded ID Loss 直接监督人脸区域，显著提升了目标身份相似度（如 GPT-Image-2 从 0.462 提到 0.499），并将复制粘贴伪影从 0.169 压到 0.055，证明显式布局锚定能让身份保持生成扩展到更大群体。
👤 Hengyuan Xu, Qixun Wang | 📅 2026-08-20

**详情:** 当场景必须包含多个指定人物时，保持身份一致性的图像生成变得越来越不可靠。除了保留每个身份之外，模型还必须将每个参考图像绑定到不同的人物和位置，而训练时的身份损失必须在多个含噪声的预测人脸之间建立对应关系。我们提出WithEveryone，一个用于生成包含多达十个参考身份的群组图像的统一框架。WithEveryone将每个选定的身份注入为带地址的标记（addressed token），预测结构化的身份—布局计划，并将该计划渲染为视觉条件。其关键目标——布局锚定身份损失（Layout-Grounded ID Loss）——利用标注的人脸区域直接监督预期身份，避免了不稳定的基于嵌入的人脸匹配；身份表征强制（ID Representation Forcing）进一步在图像合成之前为每个身份训练预测。在一个身份不相交的数据集上，WithEveryone实现了最高的目标—上下文身份相似度，将人脸相似度从GPT-Image-2的0.462提升至0.499，同时将复制粘贴伪影从0.169降至0.055。此外，它覆盖了97.3%的所请求身份，重复率仅为2.8%。这些结果表明，显式的身份—布局锚定使身份保持生成能够扩展到更大的群组，而无需依赖直接的参考人脸复制。
